ИНТЕРАКТИВНЫЙ ЗАПУСК DEEPSEEK
===============================

Это не отдельный чат-сервер: скрипт bin/deepseek запускает интерактивный
Codex CLI с моделью DeepSeek. В терминале можно писать запросы, получать
ответы, разрешать действия и продолжать разговор в той же сессии. Интерфейс
похож на текущую интерактивную работу с Codex, но модель, доступные функции
и качество ответов могут отличаться.

1. Подготовка (WSL/Ubuntu)

   Нужны установленный Codex CLI версии 0.144.0 или новее, терминал и ключ
   DeepSeek API. Для запуска чата tmux и оркестратор задач не нужны.
   Однократно установите короткую команду (в этой системе уже установлена):

     sudo ln -s /work/deepseek/bin/deepseek /usr/local/bin/deepseek

   /usr/local/bin есть в PATH у root и hgff. После установки из любого
   каталога достаточно набрать "deepseek", как обычную команду "codex".

   Ключ берётся из переменной DEEPSEEK_API_KEY или из файла
   /home/hgff/api deepseek.txt. Чтобы использовать другой файл, задайте:

     export DEEPSEEK_KEY_FILE="/путь/к/файлу-с-ключом.txt"

   Либо введите ключ без записи в историю команд:

     read -rsp 'DeepSeek API key: ' DEEPSEEK_API_KEY; echo
     export DEEPSEEK_API_KEY

   Не помещайте ключ в репозиторий, команды с ключом или скриншоты.
   Проверка конфигурации (значение ключа не показывается):

     deepseek --check

2. Начать новый разговор

   Из текущего каталога, с моделью Pro по умолчанию:

     deepseek

   Укажите каталог проекта, с которым агент будет работать. Быстрый вариант
   Flash:

     deepseek --project /work/my-project --model deepseek-flash

   Вариант Pro:

     deepseek --project /work/my-project --model deepseek-v4-pro

   Замените /work/my-project на существующий каталог. Если --project не
   указан, используется текущий каталог терминала. Если --model не указан,
   используется deepseek-v4-pro.

   После появления приглашения › печатайте задачи обычным языком и нажимайте
   Enter. При первом запуске Codex может спросить, доверяете ли вы каталогу;
   подтверждайте только для известного вам проекта. Для выхода введите
   /exit и нажмите Enter (или используйте Ctrl+C).

3. Продолжить предыдущий разговор

   Из того же каталога проекта:

     deepseek resume --project /work/my-project --last

   Без --last откроется список сессий этого проекта:

     deepseek resume --project /work/my-project

   По идентификатору, который Codex показывает при выходе:

     deepseek resume --project /work/my-project --session UUID

   Если исходная сессия была на Flash, добавьте при продолжении
   --model deepseek-flash; иначе по умолчанию выбирается Pro.

   История хранится отдельно для каждого пользователя в
   ~/.local/share/deepseek-codex, а не в обычном ~/.codex. Поэтому сессии
   root и hgff не смешиваются; продолжайте разговор под тем же пользователем.
   История и ключ не публикуются в Git.

4. Разрешения и безопасность

   Обычно агент получает workspace-write и запрашивает подтверждение для
   действий, которым оно требуется. Для полного доступа есть --dangerous:

     deepseek --project /work/my-project --dangerous

   Этот флаг отключает sandbox и запросы подтверждения. Используйте его
   только осознанно и только в доверенной среде. Для обычного чата он не нужен.

5. Если запуск не работает

   - "Codex CLI is missing": установите Codex CLI и проверьте codex --version.
   - "key file is not readable": задайте DEEPSEEK_API_KEY или
     DEEPSEEK_KEY_FILE с верным путём.
   - "Project directory does not exist": создайте каталог либо исправьте
     значение --project.
   - Ошибка доступа к API: проверьте ключ, сеть и баланс DeepSeek командой
     /work/deepseek/bin/balance. Команда --check проверяет лишь локальную
     готовность, а не ответ модели.

Проверено 24.09.2026: интерактивный deepseek-flash через Codex CLI 0.155.1
ответил на тестовый запрос в терминале. Для других версий CLI поведение
интерфейса и команд может немного отличаться.
